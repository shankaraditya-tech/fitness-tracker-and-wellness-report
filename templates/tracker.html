🛡️ Data Integrity Safeguards

To ensure clean statistical modeling, the system uses strict date-level integrity checks:

  • Duplicate Prevention: Prevents multiple conflicting rows for the same user on the same calendar day.
  • In-Place Updates: If the update checkbox is checked, re-submitting an existing date safely updates your totals.
  • Automatic Calorie Estimation: Calories burned are calculated deterministically using the Metabolic Equivalent of Task (MET) formula based on your body weight.
